# Additional recordings

The original 28 recordings come from Mark’s 2015 Virtual Ambience prototype.

| App sound                 | Creator        | Source                                                                       | Loop edit                                               |
| ------------------------- | -------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------- |
| Forest birdsong           | sama66         | [forest-bird (2).WAV](https://freesound.org/people/sama66/sounds/462136/)    | 2-second wraparound crossfade                           |
| Malaysian jungle at night | paulprit       | [Malaysian Jungle.wav](https://freesound.org/people/paulprit/sounds/591489/) | 3-second wraparound crossfade                           |
| Rain on leaves            | SamsterBirdies | [Rain on leaves](https://freesound.org/people/SamsterBirdies/sounds/584272/) | 2-second wraparound crossfade                           |
| Layered gongs             | Nirtana        | [Samples gongs0.wav](https://freesound.org/people/Nirtana/sounds/152682/)    | Trailing silence removed; 8-second wraparound crossfade |

These four source pages list Creative Commons 0 (CC0). The app versions use stereo 48 kHz MP3, with constant gain setting the pre-encoding peak to -3 dBFS. No dynamic compression was applied during conversion. Source files were left untouched.

The forest birds source comments mention faint background voices and a rooster. These remain in the recording.

Crackling fire was converted from Mark’s downloaded `444127__lurpsis__lit-fireplace.flac` with a 1.5-second wraparound crossfade. Source: [Lit fireplace by lurpsis](https://freesound.org/people/lurpsis/sounds/444127/), also listed as Creative Commons 0 (CC0).
